# Portfolio

Это репозиторий для моего портфолио.

## Запуск проекта

```bash
npm start
```

## WebSocket-сервер

Для запуска WebSocket-сервера выполните:

```bash
node server.js
```

## Деплой на Vercel

Для деплоя на Vercel потребуется использовать сторонний сервис для WebSocket-соединений, например, Pusher или Socket.io.
